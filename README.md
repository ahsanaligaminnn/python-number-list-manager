Python Number List Manager

A simple menu-driven Python program that allows users to enter five numbers, store them in a list, and view the numbers in different sorting orders.

Features
Accepts 5 numbers from the user
Stores numbers using Python lists
Uses append() to add numbers to the list
Displays the original list
Sorts numbers in ascending order
Sorts numbers in descending order
Provides a simple menu-driven interface
Allows the user to exit the program
Concepts Used

This project demonstrates:

Python Lists
for Loops
while Loops
User Input
append()
sort()
Conditional Statements (if, elif, else)
String Methods (lower())
Menu-Driven Programs
How It Works
The user enters 5 numbers.
The numbers are stored in a list.
A menu is displayed with the following options:
View Original List
Sort in Ascending Order
Sort in Descending Order
Exit the Program
The program displays the selected result.
Example

Input:

50
20
80
10
40

Original List:

[50, 20, 80, 10, 40]

Ascending Order:

[10, 20, 40, 50, 80]

Descending Order:

[80, 50, 40, 20, 10]
How to Run

Clone the repository:

git clone YOUR-REPOSITORY-URL

Move into the project folder:

cd python-number-list-manager

Run the program:

python number_list_manager.py
